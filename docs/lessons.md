# Lessons

> **This file starts EMPTY, deliberately** — per [`docs/carry-forward.md`](carry-forward.md) §3. A new
> project must not inherit a copy of a previous project's capture.
>
> **Admission bar (both must hold):** (1) **no current gate could have caught it** — if an existing
> control would have caught it and did not fire, the finding is a broken control, not a lesson: fix the
> control; and (2) **it has a named graduation target** — a file, a prompt section, a CI line.
> "Be careful about X" is not a target.
>
> **Admission implies graduation.** An entry that cannot be turned into a control within the same session
> is recorded as an open question with an owner, not as a rule. Entries that graduate are marked
> `✅ APPLIED <date>` with the operative site named, and are **not** carried forward again — from that
> point the control is the carrier.
>
> Entries are added **only by an owner-triggered Phase-8 capture session** (bootstrap Phase 8). There is
> no automatic mechanism.
>
> The six inherited principles (P1–P6) and the controls C1–C8 live in
> [`docs/carry-forward.md`](carry-forward.md), **not here**.
