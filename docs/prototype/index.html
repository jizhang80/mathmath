Walk-through A — the §7 flow (start here)

  1. Enter a problem (Tier 0 menu) → steps checked, first failure → what went wrong → hint + a guess to check → 2-question check → failed → confirmed → the small piece → back to the problem → all steps follow → answer and diagnosis.
  2. Same flow, probe passed → "not the issue"; probe declined; backtrack capped (I4); Tier 1 proposes; "none of these".
  3. Then the parent: where the student is stuck → a gap → the trend.
