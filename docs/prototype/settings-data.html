Data & telemetry Storage & updates On-device model

mathmath can send small, anonymous counts back to the project so the concept graph can be checked against real results. This is off unless you turn it on, and it never identifies you or this device.

What would be sent, if you turn this on
  • The id of the topic (node) involved — never its name in free text
  • The id of the error type, when one was diagnosed
  • Whether a check passed or failed — a plain true/false
  • Which tier answered — 0 or 1
  • The app version and the bundle versions installed
  • Counts grouped by day — never a finer time
What is never sent
  • Any free text you typed
  • The problem or steps you wrote, in any form
  • A timestamp finer than the day
  • Anything that fingerprints this device — browser details, screen size, storage figures

These are excluded by the shape of the data itself, not by a setting — there is no field to put them in.

Sent batches cannot be recalled
Once a batch leaves this device it carries no id linking it back here, so it cannot be found and withdrawn later. Turning telemetry off only stops future batches and clears what is still waiting to send.
